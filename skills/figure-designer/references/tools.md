# Choose a tool for the output

Respect a user-specified format or tool when workable. Prefer tools actually
available in the current environment; do not require a service because an older
workflow used it.

- Use a table or small code-native diagram when it fully expresses the relation.
- Use Draw.io or an available vector editor when editable shapes and connectors matter.
- Use an available plotting library for scientific or quantitative charts.
- Use an interactive visualization when exploration changes what the reader can learn.
- Use a document or presentation tool when the figure must integrate into an existing artifact.
- Use raster editing or image generation for suitable image assets, preserving source
  fidelity and following the user's actual reconstruction or editing request.

Inspect supplied references and produce the requested artifact before reporting
completion. Verify fonts, export support, and rendering with the actual environment.
Do not assume an installed desktop app, CLI, font, or library is available.

A preferred plotting stylesheet or vector pipeline is optional. Preserve an
existing workable project instead of introducing a new toolkit for a small change.
