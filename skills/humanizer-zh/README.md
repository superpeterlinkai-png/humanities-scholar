# Humanizer-zh · 公开适配版

入口是 [SKILL.md](SKILL.md)。本版适用于支持技能目录的 Codex 环境；学术稿优先使用同仓库的 humanities-writing，其他中文文本可独立使用本目录。安装本目录或使用仓库根目录安装器，不从上游另装同名版本覆盖此适配。

保留事实、归属、模态和作者声音，按授权范围处理空话、重复和模板表达。词句模式用于上下文审阅，不判定作者身份或保证通过检测器。

基于 [Humanizer-zh](https://github.com/op7418/Humanizer-zh)，参考 [blader/humanizer](https://github.com/blader/humanizer) 及 [stop-slop](https://github.com/hardikpandya/stop-slop)。许可见 LICENSE 与 licenses/。原 CHANGELOG 记录上游历史；本套改动见仓库根目录 CHANGES.md。
