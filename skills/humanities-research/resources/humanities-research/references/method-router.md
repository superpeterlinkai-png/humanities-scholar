# 方法适配：以主张和支持方式选择

先判断作品/对象、问题、期望结论、材料语言和取得条件。一般只读一个主分支；混合研究增加必要分支，并写清二者连接的推论。学科和时代提示问题，却不决定答案。

| 主张及困难 | 阅读 |
|---|---|
| 某观点是否成立；概念、必然性、理由、价值与规范 | [哲学论证](methods/philosophical.md) |
| 古代、中世纪或现代文本在其时代说了什么；版本、语言、传承与概念变化 | [历史与语文学](methods/historical-philological.md) |
| 经验怎样显现、理解怎样发生；现象学与诠释学 | [经验与解释](methods/phenomenological-hermeneutic.md) |
| 概念、主体与秩序的形成；谱系、解构、批判理论 | [批判性研究](methods/critical-genealogical.md) |
| 宗教文本、群体、仪式与生活；历史、社会、民族志或神学 | [宗教与实践](methods/religion-practice.md) |
| 文学的语言、叙事、文类、形式、媒介和接受 | [文学与形式](methods/literary.md) |
| 艺术作品、审美经验、作品本体、判断和价值 | [美学与艺术](methods/aesthetic.md) |
| 跨文化、跨语言、跨时代或跨学科比较 | [比较与翻译](methods/comparative.md) |

例如，“柏拉图的对话形式是否改变某一论证的力度”需要哲学论证和文学形式，可能再核对版本；并不因为对象古老就必须写一章社会史。“当代信徒如何理解供奉”需要实践材料，不能因为提到意义就只使用诠释学术语。

方法适配要实际改变读哪些材料、怎样分析、何种结果会迫使改判。只替换理论家名字不构成适配。超出这些分支时，建立本课题最小方法说明：对象内部的问题语言、关键材料类型、可接受支持、常见误读、适用边界，并检索专业研究来校正。
