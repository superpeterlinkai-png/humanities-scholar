# 前向测试协议（执行前固定）

日期：2026-09-22。对象：全新 humanities-scholar 套件。目的：发现设计导致的实际行为问题；不是新旧盲测，不用于宣布通用优越性。

测试员仅获得指定技能、原始合成任务材料、输出位置与边界，不获得预期答案或下列评价标准。允许读套件，不联网、不改安装、不影响外部服务。输出原样保存，评审者在看到结果后不得改写此协议。

三组测试：A 完整小论文与变更后的续写；B 哲学论证、声音适配、局部英文编辑；C 文学精读与方法跨界诊断。A/B/C 的材料均为测试合成，非真实历史/用户写作。不得以通过声音机制测试声称已拟合用户本人。

观察维度（每项用满足/部分/未满足与实际段落证据，不以总分包装）：

1. 自主完成：完成请求的正文/修订；没有停在提纲、问卷或请用户自行阅读。
2. 学术实质：对具体文本或推论做出可检查的新解释，处理有威胁的替代，限定支持范围。
3. 方法适配：根据主张选支持方式，跨方法推论有理由，时代/领域标签不决定结论。
4. 来源忠实：原始资料、推论、转述、构造材料和原始声音的状态没有偷换；无虚构引用。
5. 声音忠实：表达适配没有改变命题、归属和模态；不把合成样本或 AI 稿认作用户原生声纹。
6. 任务比例：局部编辑不膨胀，完整委托不缩水，完成后不增加无关产物。

硬失败：捏造来源/页码/经历；将单例写成普遍事实；把节选标全文；擅自形成用户固定立场；遗漏要求的实质交付。

变更复测：若出现实质失败，修改最小有关规则并只复测相关任务。静态验证与行为验证分开报告。真实长篇研究、全面学科覆盖、开放检索、跨会话恢复与真实用户声音尚需真实项目验证。
