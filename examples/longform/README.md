# 六个长文试验案例

这里公开的是 AI 生成的技能试验样本与审读记录，不代表材料提供者的学术立场。个人身份与教育背景已经匿名化；私人原文件、个人档案及执行记录不随仓库分发。

## 配置与比较方式

- **A**：整合前已经优化过的 26 项独立技能配置。
- **B**：首次整合后的 10 项配置，主要入口是研究、写作、审读。
- **C**：针对首次失败点修改长文接续、支持链审读及防御性表达后，独立重新生成的稿件；仅复测 S01 和 S05。仓库当前技能对应这一轮方法修改，并作公开匿名适配。

同题配置共享题目、材料范围与 20,000–21,000 正文汉字要求，取材与主张由写作者形成。生成完成后冻结全文，由另一审读代理在隐藏配置身份的条件下配对全文比较；相关评审随后揭示对应。协调者另行复核关键发现。每题每配置只生成一次，未控制随机性和具体取材，不将产物偏好解释为技能改动的普遍因果效果。

## 字数、来源和阅读定位

原试验十四篇共 **284,340 正文汉字**，仅计正文标记之间的汉字，不含标题、注释和书目；匿名替换造成的计数差异另列于 [metrics.json](metrics.json) 和各案例 README。正文的结构、论证与失败位置保留，匿名化引起的称谓、来源标识及局部连接另行修复。每篇的段落 JSON 给出稳定段号，以便核对评审的位置。

“匿名来源 A／B”和“影片场景资料”均为公开代号；匿名来源的原题名、日期与文献类型隐去，不据此认定其发表状态。参考文献中保留公共作者、出版社、历史材料和实际读取范围，私有原文件不分发。未核读全文、二手转引及场景材料不能代替完整观影等限制仍保留在相应文章中。

本仓库没有分发生成时的私人材料包或全部 A/B 历史配置，因此这些案例用于检查公开产物、审读依据和方法改动，不能从此包完整复跑原试验。评价针对重复、论证接续、证据与表达；没有把 AI 检测分数用作效果证明。
