# 可修订的作者档案

用于持续个性化，默认存当前研究项目，按授权范围复用，不写入系统记忆。不要凭风格推测人格、私人信仰或政治归属。

记录可以是一页文字，按需要包含：

1. 样本来源、时间、语言、文类、是否原始稿/本人修订/AI 协作，以及能确认的归属。
2. 已确认偏好及用户原话或修改依据。
3. 工作性观察：具体特征、一个短例或文件定位、观察适用的文类、证据不足处。
4. 当前思想承诺：明确认可、仍探索、已经修正的判断，分别记录；没有证据不填。
5. 当前任务的例外：期刊格式、字数、读者或语言要求。

作者可能在理论文章中使用长句，在报告中非常简洁；保留这种条件，不求统一标签。将“先辨析两个层次，再用具体例子展开”归纳为功能性习惯；不要强制每段都有二分或例子。

校准时先查思想忠实，再查表达相容：是否加入作者未承诺的结论；是否把“可能”变成“必然”；是否把细读改成口号；是否只是复制句式。合成样本只能验证机制，不能证明已经恢复真实用户声音。
