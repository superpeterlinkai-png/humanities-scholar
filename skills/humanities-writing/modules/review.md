# 学术审读与修订

读 [共同约定](../resources/humanities-research/references/research-contract.md)。先识别文类、研究阶段、用户要评价还是直接修改。探索稿不按成稿惩罚，课程论文不按博士论文扩充，成熟论证不强造缺点。

先对本稿作出判断，再给具体理由与修改。含独立讨论的稿件，先指出它形成了什么认识，以及关键分析怎样取得这一认识；只剩作者概括或不足清单时，找出值得发展的思路并按授权展开。用最强合理版本重建论文主张与支持方式，判断它是否成立、哪里写得好、哪些地方需要改。评价直接落在稿件上：例如“这两段都在解释同一概念，第二段只是另举例子却重新起问，应把例子接入前段，让它改变当前解释”。评价修订时比较实际文字，明确指出改善和仍有的问题，随后修复。方法标准按 [方法适配](../resources/humanities-research/references/method-router.md) 选择。核实实际读取范围；只能检查节选时，不给全文已合格的判断。

优先检查会改变结论的地方：关键材料是否支持对应解释；作者归属和版本是否正确；竞争解释是否被公平处理；声称反驳作者或用户旧稿时，被批评的命题是否能在原文及其相邻论证中定位，是否与原文后续保留相容；无法归属的强版本改作明确的条件性延伸，不再用其失败宣称已经反驳原作者；描述、历史、经验、规范或本体判断之间是否偷换；引言承诺与结论是否相符。每条实质意见应有具体位置、问题理由、影响与可执行修法，不能只写“加强理论深度”。

区分决定性问题、可修正局限、合理学术分歧与表达问题。已成立的部分要说明依据，保持与批评相称。评分只在用户或实际制度需要时给出，并说明标准；不要以不透明总分替代判断。

反例审查要核对它是否保留了原命题的条件、概念用法和模态，且产生真正冲突的结果。局部限定修好后，继续检查后文直接归给该作者的说法和摘要、结论中的复述；开头准确不代表全文归属已修复。判断修正是否奏效须读实际改稿，不能只凭修改说明。

用户要求修改时直接修复最小必要范围，追踪关键改动对其他段落、引言、结论与摘要的影响。证据不足时缩小、补证或撤回主张。把准确范围与归属写进修正后的解释；对旧稿的纠错留在修改说明。完整研究稿的审读，实际读取 [防御性表达组件](defensive-editing.md) 与 [词汇句式组件](ai-style-editing.md)，再检查全文并落实授权内修改；不要等生成者先自行发现缺陷才决定是否读取。专项或局部委托只读所需组件、处理指定范围。没有实际问题的词句原样保留；仅审阅时列方案，不写回文件。若多段只重复同一边界，按任务范围完成被挤掉的材料分析。连读相关段落，判断递进、比较、互证、描述或回返怎样共同处理当前问题，分段是否有材料或思路上的作用。若短段反复以作者观点起头、解释后以泛泛追问收尾，修复它们之间未完成的推理；单纯合段或改写开头不能完成这种修订。

长稿审读先对照用户最近明确的研究问题、核心主张和结论要求，再重建正文的支持链。增加材料、加强个人分析或调整组织，不自动授权替换研究问题；材料确实要求改变主张时，说明具体依据与取舍。先检查全文是否完成受托论证，再检查它自身是否连贯：一篇自洽的文章也可能答非所问。针对疑似重复说明的部分，核对它在全文中的实际作用；声称前后相推时检查前提和结果。删段或调序用于发现疑点，不能据此否定并列互证、持续描述或回返修正。核对关键引文实际提供了哪个前提、反例或需要回应的解释，后文是否用到；复述引文不是它已有论证作用的证据。连续段落即使各有成立的否定或限定，也要检查它们是否完成了用户要求的解释、重建或判断；若只累计“尚未证明什么”，继续做尚缺的分析，不能以同一边界反复收束。概述和思想比较按文类需要组织，不强迫每段互相依赖。将实际缺环及修复位置简记于已有审读记录，并回读摘要、正文与结论对用户问题的回应。

回应评审时先区分对方的事实纠错、论证要求、文类偏好和可能误解。逐项明确接受、部分接受或有理由地保留；对应实际改动与定位。未做的修改不写“已完成”，不为讨好评审接受会破坏论证的要求。必要时诚实说明材料限制。

完成相关修订与必要检查后交稿，简要说明影响判断的变化；存在影响交付的未决问题时具体交代。纯审稿委托交审读意见；不要擅自改原文件。全流程委托继续完成格式和文件验证，不停在评审清单，也不未经授权发送或投稿。

需要核实关键出处、解释或推论时，实际调用 [材料检索](source-discovery.md)、[细读](close-reading.md) 或 [论证](argument.md) 中所需项；声音审查才读 [作者声音](author-voice.md)。按稿件问题组合使用，保留审阅与修改的授权区别。LaTeX 文件另按需读 [格式复核](../resources/humanities-review/references/latex-rules.md)。
