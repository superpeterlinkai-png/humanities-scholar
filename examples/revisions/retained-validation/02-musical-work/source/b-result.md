# 请求一

不同演奏者能够演奏同一首曲子，而他们在速度、音色与乐句处理上可以明显不同。这意味着，作品的同一性不能要求各次演奏在所有具体属性上完全一致，否则我们就无法承认这些有差异的演奏仍属于同一作品。然而，容许差异究竟承诺了什么？它要求我们区分作品的身份条件与单次演奏的全部声音特征，却尚未要求我们承认一个脱离一切演奏而存在的抽象实体。

从这里走向“作品是脱离一切演奏的抽象实体”，还需要一个未被说明的前提：凡能在不同事件中保持同一性的东西，都能独立于这些事件及其相关活动而存在。这个前提并不包含在最初两点之中。“不等于任何一次演奏”与“不依赖任何演奏”回答的是不同问题。前者涉及对象的同一性，后者涉及对象存在的条件；若没有进一步论证，不能把同一性的区分直接变成存在上的独立。

可以设想，一个共同体通过传授和演奏维持一首没有乐谱的曲子，并允许速度、音色和乐句处理有所变化。在这个思想实验中，人们依照传承中的辨认与纠正方式，将不同演奏归于同一作品。作品没有被等同于任何一次演奏，却可能依赖这一持续的实践才得以存在。这未必是音乐作品的正确理论，但它展示了一种与最初两点相容的解释；只要这种可能性尚未被排除，抽象实体论就不是那两点的必然结论。

对此可以反问：共同体认不认得作品，只关乎人们如何接触它，怎么能够决定它是否存在？这个反问有力，因为辨认条件确实不能直接充当存在条件。然而，它同时限制了双方的推论：我们既不能从通过演奏辨认作品，推出作品只能依靠演奏存在，也不能从辨认出跨演奏的同一性，推出作品已经独立于演奏存在。上述思想实验的作用，在于揭示解释上的选择，而非证明实践依赖论。

我的暂定判断是：我们应当承认作品具有超出单次演奏的同一性，但暂不把这种同一性解释为脱离一切演奏的存在。这里的“超出”有明确而有限的含义：一次演奏中的每项声音特征，不会自动成为作品的身份条件。不过，哪些差异仍属于同一作品，仍需判准；最初两点只表明部分差异可以被容许，不能保证任何差异都无关紧要。因而，备忘录真正支持的结论，是作品不能由某一次演奏的全部具体属性来定义。抽象实体论可以成为进一步说明这一结论的方案，却还没有取得唯一解释的地位。
