# 概念与理论的实际工作

读 [共同约定](../humanities-research/references/research-contract.md)。先说明概念在哪个具体解释或推论中出了问题；没有问题，不为了术语精致而增加区分。

重建概念在文本或实践中的使用：它用来识别什么、与什么形成区别、允许什么推论、排除什么、依赖哪些前提。定义是证据之一；比较实例、反例、边界例及相邻用法，检验实际外延和功能。分别标明行动者用语、学者分析范畴和本文提出的新定义。

发生含混时先判断是同词异义、层次变换、历史变化、隐喻转用，还是生产性的歧义。只有实质影响解释才消歧；不要替有意保留张力的文本建立假精确。新概念需要说明它使什么工作成为可能，不能以更抽象词语重复原问题。

选择理论时在一段真实材料或一个具体问题上试用：不使用它时怎样理解；使用后增加什么可辩护的理解；它的前提在哪里可能不成立。比较合适的替代解释，检验关键差别，而非把理论数量当作深度。借来的理论受到材料抵抗时允许修改理论或放弃使用。

跨作者、跨学科转移要注明功能变化：同一词不自动指同一对象。例如从经验的呈现结构到作品的存在方式，需要额外论证；从仪式的规范文本到参与者的实际体验，需要另一类材料。可保留张力和有限关联，不强造统一体系。

提出独创的区分、模型或重描述时，给出它的根据、相对于旧解释的收益、可能反例及范围。无须每次提出新术语。把最有用的结果写成能进入论文的论证，而不是只交术语表；必要时转入 [论证检验](../humanities-argument/SKILL.md)。
