# 请求一

不同演奏者能够演奏同一首曲子，而速度、音色和乐句处理又可以不同，这首先说明作品的身份不由某一次演奏的全部声音特征决定。假如某次演奏的速度就是作品必须具有的速度，另一速度的演奏便无法属于它；备忘录却承认两者仍是同一作品。因此，我们已有理由区分作品的身份条件和演奏的具体实现。但 C 进一步要求作品在存在上脱离一切演奏。这里发生了一次推论的扩张：从“不与任何单次演奏等同”，转到了“不依赖演奏及其相关活动”。前一个判断可以成立，后一个判断仍须得到自己的理由。

可以构造一种口传音乐实践来检验这一步：学习者依照传授的旋律演奏，速度和音色有所变化，改变某些音符却会被纠正。这里，同一作品的身份表现为一种有选择的约束：它容许部分变化，也使另一些变化成为演错。约束通过记忆、传授和纠正持续发挥作用，所以某次演奏结束，作品仍可供下一位演奏者学习。这个模型同时容纳 A 的跨演奏同一性和 B 的演奏差异，而作品的延续依靠整套实践。没有正在发生的演奏，与从来无须任何演奏及相关活动，便显出不同含义：前者只是实现的间歇，后者才是 C 所声称的存在独立。

抽象实体论可以提出更强的理由：如果没有一个共同对象，人们凭什么纠正演奏，而不只是把喜欢的声音任意叫作同一作品？这个问题要求解释标准怎样约束判断。口传模型可以回答：学习者面对的是已经传授、能够复现并供人比较的音乐结构；个人的临时偏好无法独自决定哪些音符算演错。标准因而可以超出某一次判断，同时由共同实践维持。标准有公共约束力，并不要求它在全部实践消失之后仍然存在。我们在思考中提取演奏共有的结构，也不因此证明这种结构具有独立的存在方式；提取说明比较怎样进行，独立存在则关乎被比较的对象靠什么延续。

我的判断是，D 揭示了 C 所跳过的一层关系。作品能够使不同演奏成为“同一首曲子的演奏”，正因为它的身份允许选择性的变化；这种约束不会随着某一次演奏结束而用尽。由此可成立的是作品相对于单次实现的独立，而不是脱离一切实现条件的独立。口传模型使这一区分获得了具体内容：作品可以超出每一次演奏，却仍依靠各次演奏之间的传授关系延续。要由 A、B 得出 C，就必须排除这种依赖模型。A、B 本身给出的，是跨演奏保持身份的要求，尚未替我们选定满足这一要求的本体论。

短注：D 被推进为对两种独立关系的区分；口传思想实验进一步说明，身份标准怎样约束不同演奏，又怎样可能依靠实践延续。
