# C：开灯短篇的细读与方法范围

## 材料与任务

本次完整读取 `source/case-c.md`、`source/c-result.md` 及 `source/evaluation-protocol.md`。`source/` 是原文件的逐字节快照。短篇由测试者构造，原文的 P1—P4 编号继续使用；以下“旧稿第几段”则是本次按旧结果六个正文自然段自编的审读定位，不含方法附注。

任务要求 700—1000 字细读“没有等”的作用，自主形成解释，并另附约 150 字的方法判断。本次交付 `revision.md` 的完整正文与方法判断；没有把附注扩成研究计划。

## 主要判断

旧稿已有清楚而可检查的主张：反复否认使牵挂持续出现，七点、路线改变、雨中行人及坏灯都参与这一解释。它也正确保留了“没有特意记住”与“没有记住”的区别。需要修复的主要问题是，若干段落写到有价值的关系后，转去阻止尚未出现的夸大读法；末段把等待直接说成已确定的事实，又略微超出了细读能给出的结论。修订继续发展旧稿已经找到的行为与自述之间的关系。

## 问题定位与落实

| 位置与原句 | 判断及影响 | 本次改法 |
|---|---|---|
| 第 1 段：“无法直接承认的牵挂，借否认获得了持续出现的机会。” | “借否认持续出现”是有效解释。“无法”则容易把文本的叙述安排写成已知的心理能力限制；材料只显示叙述者没有明说。 | 新稿从否认产生的作用入手：它让叙述者继续守候，同时不必承认对象；以行为与自述的关系展开。 |
| 第 2 段：“街暗只能说明为何需要灯，尚不能充分说明为何必须在七点。” | 这是一项可追问的不相称，但单凭七点不能证明私人动机；夜间照明也可以有固定时刻。 | 新稿把七点与 P2 的“仍”、邮差改道和早到十分钟一起解释。关联的根据来自叙述安排，避免把一个时刻独自用作动机证据。 |
| 第 3 段：“能够复述并不证明曾有意记忆”；“否认只撤去主动留意的姿态”。 | 否定范围的区别准确，直接决定对“没有特意记住”的解释，必须保留。 | 新稿把区别写进一句连续分析：否认有意记忆，复述却让对方的话再次出现。继而说明叙述怎样保存它。 |
| 第 3 段末：“却不足以确定两人的关系。” | 关系性质确实未给出。旧稿没有把它写成恋爱事实，因而这里作为段末警告没有推进眼前的语言分析，且末段又重复一次。 | 新稿以“对人的牵挂”承担所需范围，不另列关系类别，也不添人物背景。 |
| 第 4 段末：“不能据此断定所有叙述都不可信，更不能补写下雨时邮差必定不来的情节。” | 这两项强说法此前没有在正文提出，也不是任务需要评估的读法，是最明确的预防性插话。删除不会丢失已有证据边界。 | 删除并补完母亲停止追问的作用：可见反例使解释失效，沉默又让叙述者暂时免于给出新说法。 |
| 第 4 段：“读者因而承担继续追问的工作。” | 能描述阅读效果，却把接下来可做的分析留给了读者。 | 新稿直接写出谁看到了什么、对话停在哪里，以及沉默怎样维持未明说的关系。 |
| 第 5—6 段：先解释 P4 的灯坏、空屋与邻灯，再另起段提出对旧居和习惯的依恋。 | 替代读法合理，但旧稿主要将它当作需要排除的竞争者，尚可进一步说明告别旧居与牵挂是否可能共同由七点的习惯承载。 | 新稿把 P4 与替代读法放在同一分析段中，说明固定时刻怎样连接人物行程与旧居日常；邮差细节决定这一读法的具体范围。 |
| 第 6 段末：“结尾保留的并非‘究竟有没有坐着等待’这一事实谜题”。 | “坐在空屋里”是明写的动作，“等待”涉及对动作的理解；旧稿在这里把较有根据的解释收紧成已确定的事实。 | 新稿以整篇论证支持等待的读法，不宣称已消除事实与动机的一切歧义。结尾落在行动持续、话语否认的同时存在。 |
| 全文分段。 | 旧稿逐段处理 P1—P4，便于定位，不能只因短段多就判为错误。实际问题是独立开场、逐段提醒及另设替代读法，使同一解释多次停下。 | 新稿四段依次形成主张、连读 P1—P2、分析母亲介入、将 P4 与替代读法一起完成。P1—P2 合读有“仍”这一实际连接，合段伴随新增关系分析。 |

## 应保留的否定与方法附注

原文“不是等人”“没有特意记住”“当然没有等”是分析对象，全部保留其措辞与否定范围。正文指出照路理由与雨中行人冲突，是由原文支持的反驳，也保留。方法判断则由输入明文要求，不能被当作多余免责声明删去。

旧方法附注已正确指出虚构文本不能证明历史家庭生活，且时代、城市、作者未给出；建议限定范围、比较来源与检验反例，也与问题相称。新稿主要压紧表达，保留“所有”家庭这一量词的证据要求，不添加调查步骤、时间表或外部文献。
