# 验证报告

日期：2026-09-22。对象：humanities-scholar 1.0.0。结论：本版已完成文件结构验证、安装保护测试和受控前向测试，可以作为新体系投入具体研究；这些结果不证明专家水平、全学科可靠性或优于旧版。

## 静态与安装验证

- 10 个技能均通过本机 skill-creator 的 `quick_validate.py`。
- 35 个技能文件逐字节 SHA-256 核验通过；45 处本地 Markdown 引用均解析到包内文件。
- UI 名称、描述长度、默认调用语句和自动发现设置已检查。
- 安装器使用 Python 标准库；试装 10 个技能后逐文件核验。重复安装在写入前被拒绝，既有文件字节保持一致，无关文件保留。
- 人为修改测试副本中的技能后，安装器在创建目标目录前拒绝该副本。
- 实际安装到 `<USER_HOME>\.codex\skills`，返回 10 个技能、35 个文件核验成功。首次使用裸 `python` 的提升权限命令空输出失败，确认没有写入后，改用已核实的解释器绝对路径成功；不是自动审批拒绝。
- 当前会话的技能目录清单不会由本报告宣称已刷新；新任务中的自动选择与相近旧技能之间的竞争尚未实测。显式调用 `$humanities-research` 可以指明所需入口。

## 前向测试方法

执行前固定的 [协议](evaluation-protocol.md) 规定六个观察维度：完成实质任务、学术分析、方法适配、来源忠实、声音忠实和任务比例。三个独立执行代理只取得任务材料、技能和输出要求，没有取得预期答案或评价规则。测试不联网，不动外部资料，全部案例及声音样本都是明示的合成材料。

这不是旧版/新版盲测；评价由设计者依据实际产出作出，没有独立盲评者。不能据此排除模型自身能力、任务选择或设计者判断带来的影响。初始哲学案例与方法文件中的音乐作品示例接近，因此主要检验执行机制；随后追加不同对象的自由问题作探索性迁移检查，不能追称为原协议预先确定的任务。

## 实际观察

| 任务 | 观察到的结果 | 限制与处理 |
|---|---|---|
| A：宗教实践微型论文 | 交付完整正文；区分规约的理想、事件记录与申辩；对“自律占主导”给出有限判断；处理外廊、目光和听不清的具体细节 | 给未编号 M4 写成了“§1”，未说明自行编号；初版不能称无问题通过 |
| A 后续：M2 失去事件依据 | 撤回现场干预与空间差别执行的推论，改写正文并同步改写摘要；保留 M2 作为故事材料的可能用途 | 原引注问题仍被继承，说明来源更正不自动完成全部引注审查 |
| A 引注审读 | 更新共同约定后，由另一执行代理按审读任务修正 M4 定位，并补注 M2 更正的来源；保留论证与其他措辞 | 这是有目标的修复检查，不证明以后不会再出现类似错误 |
| B：音乐作品论证 | 交付完整正文，指出从作品同一性到独立存在的桥接前提，以构造例子检验；回应“取得条件不等于存在条件”的异议 | 有限的概念练习，没有核查实际哲学学术史；与包内示例接近 |
| B：两句英文编辑 | 只局部修改句式，保留否定、可能性和 access/existence 区分 | 不能由两句推出长期声音适配能力 |
| B 追加：无误预判与自由 | 提出条件性必然与自主的区别，认真处理“过去已固定”的强异议，并给出有代价的暂定立场；没有虚构古代学派归属 | 只证明这个构造案例中的局部分析表现 |
| C：文学细读 | 从“七点”“仍”“没有特意记住”“当然”等措辞与结尾结构论证；比较习惯依恋读法并保留情感关系的不确定性 | 仅一篇短构造文本，无文学史检索 |
| C：由小说到社会概括 | 明确材料不能证明任何时代所有家庭的情感结构，提出范围、来源与比较要求 | 没有实际开展历史或经验研究 |

## 据观察作出的修改

在共同研究契约中补入：未编号材料使用标题或开头词定位；工作性编号须标明自行编制，不能伪装为原有章节号。没有为一次失误增加每段必填表格或新的用户批准环节。

安装验证脚本首次运行暴露本机 Python 未自动把脚本所在目录加入模块搜索路径，已明确加入当前包路径；随后静态检查和安装保护测试通过。这一问题与学术能力无关。

## 尚未得到的证据

尚未检验开放网络检索的文献覆盖、真实长篇原著解释、完整长篇论文的跨会话推进、古典原语与不同传统的全面适配、真实田野/档案工作，以及对当前使用者原生文章的声音忠实度。合成作者样本仅检查适配机制，不属于用户个人写作证据。

这些需在实际课题中以具体材料与用户修改检验，不能靠增加规则数量或自评分数宣布解决。已有明示偏好可立即使用；个人声音档案仍应由原始文章与本人纠正逐步校准。

原始任务与输出保存在 [validation](./) 目录，未把错误初稿改写成成功记录。技能文件校验见 `MANIFEST.json`。
