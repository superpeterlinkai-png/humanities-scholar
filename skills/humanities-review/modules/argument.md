# 在材料中发展论证

读 [共同约定](../resources/humanities-research/references/research-contract.md)。本模块帮助完成解释、概念分析、推演或批评；支持方式按 [方法适配](../resources/humanities-research/references/method-router.md) 选择。

## 做出决定答案的分析

从值得解释的材料着手，提出最有理由采取的读法，并沿着它持续工作。细察措辞、重述一个经验、改变比较条件或返回先前的例子，让对象的关系逐渐清楚。选择什么动作，取决于这处困难如何才能被想透。研究的产物是这一过程形成的认识。需要时实际读 [分析如何展开](../resources/humanities-writing/references/argument-development.md)：其中的路径和完整例子用于选择做法，不规定文章或段落的统一结构。

从概括走向分析，关键是写出读者尚不能从概括直接得到的关系。复述一个概念的名称之后，把它用于一处具体材料，解释哪些细节因此得到不同理解，为什么。遇到“更根本”“构成”“实现”等词，追查此处究竟是哪一种关系，并说明它怎样在材料中运作。分析也可以逐步改变问题的概念配置；用户的任务目标和已确认取舍继续有效。

在工作文本里保留正在形成的解释，随后继续做它提出的工作。材料、读法、所得之间的支持关系是内部诊断依据，不是每段按顺序填充的栏目。一个分析单元可以跨段，也可以将描述、引文、辨析和判断集中展开；组织由读者理解所需决定。递进、并置互证、回返修正、持续描述各有用途，只有声称前后相推时才要求严格的线性依赖。

## 让检验改变理解

决定结论的一步受到真实竞争读法、反例或材料冲突挑战时，重建对方最强的合理理由，并实际处理它。先在原文、任务或自己的论证中定位待检验的命题；比较时保留其对象、条件和断言强度。自拟思想实验说明其性质及被改变的条件。

检验的结果要进入论证：它可能确认解释、改变概念、缩小主张，或揭示尚未成立的前提。没有实质分歧时继续把自己的解释做充分，不为形式完整制造反对者。否定结论本身可以是重要所得，需要展开被排除的关系及理由。成文呈现修正后的解释，校审意见留在工作记录。

演绎推论核对前提和推演；文本解释把措辞、形式与整体关系说明；现象描述通过观察角度、时序或条件变化显示其结构；历史解释连接来源、时序与机制；规范判断交代价值理由；溯因比较各读法怎样解释决定性细节。选择适合当前问题的支持方式，具体标准见方法分支。

## 用所得完成任务

用取得的认识完成受托问题。直接作出判断，展开使它成立的理由；若分析改变了最初读法，就写清这种改变带来的理解。结尾仍在布置本篇应做的分析时，继续处理那一处材料和推论。

检查各部分怎样共同处理问题：有的是前提，有的是对照、现象变式、回读或新后果。只有再次命名问题、重复归属或换作者复述时，回到材料补缺或精简。全流程委托把所得接入 [写作](writing.md)；局部分析直接交付当前所需内容。
