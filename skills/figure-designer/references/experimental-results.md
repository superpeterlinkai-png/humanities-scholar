# Quantitative figures

Use only when quantitative evidence is actually part of the task. Preserve the
source data, units, denominator, category definitions, and uncertainty.

Choose a chart by the relation: points or intervals for estimates, lines for ordered
change, bars for quantities encoded by length, scatter for relationships, and a
table when exact values matter more than a visual pattern. Do not force a performance
comparison on interpretive or historical material.

Represent missing data explicitly where it affects interpretation. Explain
aggregation and transformations. Do not invent observations, confidence intervals,
statistical significance, or repeated runs. Planned values belong in a clearly
labeled illustration, not a results figure.

Choose honest scales. A bar chart's length encoding ordinarily calls for a zero
baseline. A line or scatter chart can use a restricted range if its scale is clear
and does not exaggerate the conclusion. Label log scales and breaks.

Use color and emphasis to clarify relevant evidence. Include uncertainty when
available and distinguish it from variability. Captions and accompanying prose
should state what the data establish and where interpretation begins.

Render at the intended size and check labels, legends, clipping, contrast, and
data-to-mark correspondence. Use an editable or reproducible source when it helps
the user maintain the figure; do not require an unrelated export format.
