# Three copy-ready turns

Start a fresh conversation in the repository. Do not provide the worked output.
Read each actual result before proceeding. The second turn makes a substantive
authorial choice explicit; it is part of this demonstration, not a default rule
that every prose edit needs additional approval.

## Turn 1 — Review only

```text
使用 $pre-submission-reviewer。读取
examples/walkthroughs/02-argument-and-translation/input.md。
可以读取 skill 说明，但不要读取 worked-example.md，不要联网。

只审查给定段落，不写完整期刊审稿报告，也不要重写。指出关键推理在哪句话发生，
缺少什么前提，给出最强的替代解释。区分作品同一性、阅读经验和解释的有效性；
不要替作者决定本体论立场，不要添加学者名字、引文或读者研究。
保存为 work/case-02-review.md。
```

## Turn 2 — Authorise a specific revision

```text
我选择较弱的结论：阅读经验的差异本身不足以决定作品的同一性，也不足以证明所有
解释同样有效。我明确授权把原段落修订为这一立场，保留原来的可能性例子。

使用 $paper-writer，根据原始输入和刚才的审查结果写一个中文段落。不要添加外部
事实或引文，不要声称已经建立完整的作品本体论。段落后用简短说明标出哪些论证
变化是实质修订。不要读取本案例的 worked-example.md，也不要联网。
保存为 work/case-02-revision.md。
```

## Turn 3 — Translate the accepted revision

```text
使用 $paper-polish，将 work/case-02-revision.md 中的修订段落译为自然、精确的
学术英语。以该中文修订稿为准，保留所有可能性、否定和范围限定，不再扩展论证。
段落后简短解释“作品同一性”“阅读经验”“解释有效性”的译法，并核查有无意义
漂移。不读取 worked-example.md，不联网，不添加来源。无需翻译修订说明。
保存为 work/case-02-translation.md。
```
