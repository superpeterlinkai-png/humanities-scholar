# 形成可辩护的论证

读 [共同约定](../humanities-research/references/research-contract.md)，按 [方法适配](../humanities-research/references/method-router.md) 确认支持方式。不要把所有论文重写成形式逻辑，也不要让修辞流畅掩盖关键跳步。

从当前最佳解释出发，明确它相对于问题到底改变了什么。用户未给论点时，依据材料形成暂定主张并推进；不以“我不能代替你思考”为由只给空白结构。

检查决定结论的支持链：理由或材料是什么；为什么它支持此判断；是否缺少桥接前提；范围和模态是否超过支持。演绎论证看有效性与前提，溯因论证比较解释力与代价，诠释论证检验细节与整体，历史解释检验机制、时序和互证，规范判断说明价值前提。不同方式不能相互冒充。

主动尝试能推进理解的动作：拆开被混同的层次；解释被通说遗漏的细节；提出反例；揭示某理论的内在困难；展示两个貌似对立的说法各自成立的条件；发展可解释更多材料且代价更小的读法。选择由问题需要决定，不能每篇文章做完一遍。

构造真正有威胁的反驳，定位它攻击的是文本归属、前提、推理、适用范围还是价值立场。判断是推翻主张、要求缩小，还是能够回应。回应必须增加理由、修改概念或接受损失，不能把原结论重复一次。若没有有力异议，不制造虚弱对手。

自拟的极端立场可以检验逻辑，不能自动代表真实学者。把对手加强后若与本文相容，贡献应说明为补充、澄清或限定，不写成击败既有研究。批评较强命题时保留较弱命题的可能性，例如“必须有一次有意注意”不等于“全程持续自我监控”。反例须保留被检验命题的适用条件；条件外成立的案例可以划定边界，不能自动反驳条件内的主张。

做一次有区分力的检验：什么材料或反例会使竞争解释的排序改变？找到后实际分析。资料不足时交代哪项判断仍悬而未决，保留可成立的部分。论证可以得出有限的或否定的结果，但要说明读者因此获得什么理解。

若解释先排除某类材料，再据此宣布反例无关，检查它是否用自己的结论决定检验范围。以已声明的研究对象、覆盖范围和有依据的竞争解释检验；允许有理由地缩小结论，不能保留整体主张却免除对应的证据责任。

对照研究问题与结论，检查中途是否悄悄更换对象。新证据改变主张时，一并更新依赖它的章节、引言与摘要。交付论证成文或用户要求的诊断；全流程任务继续到 [写作](../humanities-writing/SKILL.md)，不要止于逻辑提纲。
