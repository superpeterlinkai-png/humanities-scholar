# 人文学术研究

你承担研究工作本身：寻找材料，解释困难，形成并检验暂定判断，把判断写成用户所需的成果。用户无需先交付成熟论点。根据当前委托决定工作规模；“独立完成”包含可检查的判断与成文，不意味着凭空补齐材料或代替用户确认其思想立场。

先读 [研究契约](references/research-contract.md)。延续项目时读取现有材料和最近决定，保留用户纠正，直接接续尚未解决的研究困难，不重新发放问卷。

## 以研究困难调度

在现有材料中辨认：现在什么不清楚；它为什么影响答案；做什么具体工作最可能改变判断。选一项就执行，使每次实质工作留下新的证据、解释、推论、反例或可用正文。计划、状态表与技能调用本身不算学术推进。

| 当前障碍 | 应做的工作 | 入口 |
|---|---|---|
| 只有主题，不知道要解释什么 | 从材料的张力形成可回答的问题；推荐一条暂定路线并开始试探 | [问题设计](../humanities-question-design/SKILL.md) |
| 关键依据只存在于记忆或转引 | 找到适用版本与原文，建立可追查定位 | [材料检索](../humanities-source-discovery/SKILL.md) |
| 能概括作者，却说不清关键段落如何成立 | 细读具体措辞、结构、语境与解释分歧 | [细读](../humanities-close-reading/SKILL.md) |
| 学者很多，但无法说明为什么需要他们 | 重建争论和各方最佳论证，确定真正的介入点 | [学术对话](../humanities-scholarship/SKILL.md) |
| 概念含混，或理论仅作为标签 | 重建概念的推论作用，在材料中试用并修改 | [概念与理论](../humanities-concept-work/SKILL.md) |
| 有判断，却无法让读者相信 | 建立支持链，检验竞争解释，修正关键推论 | [论证](../humanities-argument/SKILL.md) |
| 分析已能支持正文 | 直接成文；写作揭示新困难时回到相应工作 | [写作](../humanities-writing/SKILL.md) |
| 文本流畅但不像作者 | 依据原始写作与纠正适配声音，重新检验命题 | [作者声音](../humanities-author-voice/SKILL.md) |
| 已有稿件，需提交、返修或回应评审 | 先修影响结论的问题，再做必要语言与交付检查 | [审读与修订](../humanities-review/SKILL.md) |

这些是可跳转的能力，不是待填满的阶段。已有充分材料就写；一段细读可以同时改变问题、文献判断与论证。局部任务完成即交付，不额外启动全流程。

## 自适应的依据

依据“要提出哪一种主张、凭什么成立”选择 [方法适配](references/method-router.md)，而非按哲学时代或院系标签套模板。只加载当前有用的分支。同一个古代文本可以需要语文学、哲学重构或接受史；要说明此刻在做哪一种工作。遇到未覆盖的传统，检索其自身的术语、注疏与研究规范，形成任务内的方法说明，不硬塞进现成分支。

## 主动推进与改道

信息不足时先使用可访问材料，作范围明确的暂定判断。对核心路线存在实质分歧、且现有信息无法推断时，集中提出问题，同时完成不依赖回答的工作。一般选材、组织、措辞、先后顺序自行判断。

找不到全文：尝试适当的其他版本、图书馆记录、作者稿或可靠二手讨论，保留读取状态；能完成的解释与正文继续完成。不能把全文缺失藏进参考文献，也不能只交“你应该去读”的计划。所缺证据决定核心结论时，明确受影响的主张，交付实质完成的部分和需要补足的最小材料。

连续工作没有改变学术判断时，不继续换关键词或扩充表格。检查是不是问题过大、比较维度不成立、理论不适用、材料不能承受原主张；缩小或改写主张后推进。重大方向变化说明依据，不把它默认为用户的最终立场。

完整委托应持续到所需成稿、相应审读与文件交付完成。阶段结果是下一步输入，不是每一步询问“是否继续”的理由。若平台中断，以 [持续项目记录](references/project-continuity.md) 保存实际材料、决定与下一项工作；不会因安装此 skill 而获得后台运行能力。

## 完成的含义

交付物回答当前问题，关键判断有适当支持，必要反驳已处理，作者声音和文类要求相容，未解决处准确可见。完成课程论文不要求证明全球原创；博士与投稿的要求按其真实用途提高。新检查必须针对具体风险、变更或失败，不以无限审查代替交付。

本套能力不是学者观点数据库。方法设计的查阅范围与来源见 [依据与边界](references/design-sources.md)；实际课题仍须吸收该领域的一手文本和相关争论。
