# 材料检索与核实

读 [共同约定](../humanities-research/references/research-contract.md)。先明确要支持或检验哪项判断，复用用户已有目录、课程阅读、引文库和可访问文件。跨文件先按标题、作者、概念与原语关键词作有界检索，不扫描无关个人资料。

检索围绕问题展开：原始措辞及其变体、异名与译名、对象所属的争论和时期。通过一项可靠起点的注释/书目向前回溯，再查后续回应；寻找有力异议和不同语言的专业研究，不把搜索排序当学术地位。综合数据库、大学图书馆、出版社、期刊与作者存档的实际覆盖；某一论文平台未收录不构成不存在证据。

材料选择要解释它承担的作用：原始依据、语境校正、解释竞争者、理论工具或反例。经典地位只能说明值得查，不自动成为必引文献；边缘或地方来源可能对当前问题更有证据价值。

拿到材料后区分元数据验证与正文检查。确认作者、题名、版本、时间和稳定链接；只有 DOI 确认了才写入。找到全文后阅读承担关键判断的段落及必要上下文，确认说话者、否定、转述与作者最终立场；不得把设靶段落误当赞同。追引到原文失败时保留“转引自”。

网页元数据冲突或同名文本有多个版本时，先查看实际文件的题名页、刊头、版权或页眉，再与出版/馆藏记录核对。栏目名称、抓取日期不能代替刊名、发表年；期刊版、书章版和作者稿的定位不直接换算。下载或提取成功后检查可读正文，挑战页、空页标记和乱码不计作取得全文。

全文不可得时依次考虑合法可访问版本、作者稿、馆藏记录、已授权数据库与可靠二手讨论；访问边界按实际工具处理。几个有效路径失败且重复结果时，报告具体缺口，换可支持的论证路线或继续其他部分。不可伪造购买、登录、下载或阅读结果。

交付以可用材料和它能支持什么为中心。长项目在现有记录保存：来源、版本/语言、读取范围、定位、支持的主张、限制。决定性文字还应区别未经校勘的转录、来源明确的文本抽取与已核对的原页；独立引证只能互证对应位置，不能认证整份转录。简单查证只需给出结果和链接。不能把大量摘要填进表格当作已经完成精读。

建立文献综述时将核实的材料交给 [学术对话](../humanities-scholarship/SKILL.md)；决定性段落交给 [细读](../humanities-close-reading/SKILL.md)。检索的结束条件是当前判断得到足够支持和必要反证检查，不是达到书目数量。
