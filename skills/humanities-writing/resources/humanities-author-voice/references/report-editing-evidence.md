# 编辑证据记录方法

本文件是通用记录说明，不含个人报告、对话摘录或真实作者档案。根据当前任务，在私人工作区记录必要证据即可，不要求每次建立新表格。

每项记录保留：实际请求与适用范围、原句与本人改句、选择或拒绝的理由、证据性质及仍未确定之处。区分作者本人观点、对所读作者的转述与编辑建议；对转述的亲自修改只证明该处的表达取舍。

保留概念关系、来源归属、否定范围与模态。对“不能由 A 推出 B”的改写仍须保留被否定的推论；不能为避开高频句式，只留下 A 的正面陈述。术语、长句、第一人称和必要犹豫按实际作用判断。

只列方案时不写回；按编号选择后只落实选中项。替换后核对相邻句的主语、指代、旧句残留和引文归属。编辑造成的缺陷不应学成作者习惯。

个人偏好与通用能力分开维护。任何后续公开导出都排除姓名、文件名、学习经历、私密样本及逐次对话记录。
