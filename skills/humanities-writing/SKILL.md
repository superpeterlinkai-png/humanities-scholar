# 研究成文

## 按委托进入

- 起草或翻译：沿用下面的成文指南，分析不足再读相关研究模块。
- 只查模板词句：先读 [词汇句式](modules/ai-style-editing.md)；有空泛辩解时一并读 [防御性表达](modules/defensive-editing.md)。不要顺带校正全篇语病或改结构。
- 匹配本人学术语气：读 [作者声音](modules/author-voice.md)，按实际样本和本人改句校准。
- 先列方案或仅落实编号：沿用上述专项的审阅／选择边界，只交所需结果，不启动全文研究与审稿。

## 入口与模块

本入口负责当前委托，内部专项按需一并读取；目录列出文件不等于已执行。无需把所有模块读完再开始，也不按固定研究阶段逐项运行。模块之间的交接保留来源定位、归属、模态、已有结果、未决处和用户冻结内容。已读模块直接沿用，双向引用不启动循环。


读 [共同约定](resources/humanities-research/references/research-contract.md)。根据用户需要交付正文，沿用现有稿件、材料和已作判断；要全文就完成全文，要一段就只写所需段落。材料与核心论证不足时直接补做相应研究，而不是让用户先提交全部论点。

明确正文要回答的问题、允许的篇幅和证据范围。思路仍探索时写可检验的暂定论证，不冒充已定稿。适当的具体分析可以先写，以其结果调整结构；不要求先确定每个标题。

跨节长稿实际读取 [持续项目](resources/humanities-research/references/project-continuity.md)，在已有笔记中保留决定性原文、解释条件、已取得的结果及尚未完成的推论；接续前先读这些记录和对应正文，不能仅凭提纲结论扩写。新材料若只是再证同一区别，说明它为何改变判断，或将其收为简短佐证；让后文使用已有结果处理剩下的问题。篇幅不足先补真正缺少的细读、竞争解释或推理，不能靠重申边界、轮换理论家或延长总结凑足；材料无法承受指定规模时如实说明缺口。记录服务于接续，不规定文章的章节、段数或每节必须提出一个新主张。

先依据当前任务的文类、目的、读者与具体要求选择组织方式。阅读报告可按作业需要交代阅读材料与关注，这只是文类示例，不规定研究论文或其他写作的开头。研究论文的具体结构从研究问题、材料、方法与目标要求中形成；文献综述、研究计划、讲稿等按其实际任务组织，不套同一开头—主体—结尾。用户对某篇文章或某部分的修订要求只在其适用范围内落实。需要论证的部分，让读者看到措辞、形式、历史关系或前提怎样支持判断；给相互依赖的分析以充分篇幅，在材料关系或推理方向发生实质转折处换段，后段使用前段已建立的认识继续推进。作者或引文的更换不自动构成段落边界；以介绍或重建作者思想为任务时，按说明需要安排。第一人称、阅读经历、课堂背景与提问按当前文类及所在部分的作用取舍。检查整段及段间是否完成当前任务，不能用逐人转述、泛泛追问或统一段落模式代替所需的分析。删去防御性插话后，完成其中尚未解释的关系。

需要个人声音时读 [作者声音](modules/author-voice.md)，利用当前样本与明示偏好。思想忠实优先于表面相似；新增解释可以写进暂定稿，但在交付说明中标出尚待用户确认的实质取舍，不把整篇变成括号和警告。

学术文类与翻译的特殊要求见 [成文与交付](resources/humanities-writing/references/genres-and-delivery.md)。叙述作者思想时保持归属；轮到本文主张时给出理由。不要让大师名词和引文密度替代作者自己的分析，也不要通过删光学术对话来制造“原创声音”。

完成后沿正文的问题检查推理如何接续：后段用到了前段取得的什么认识，又凭什么向下一步推进。用户列出的概念、作者或讨论顺序规定需要覆盖的内容，不自动构成逐项转述的段落结构；需要连贯论证时，把它们在当前问题中的关系写出来。检查正文提出的关键问题是否已得到分析；仍未决的问题说明相争的解释和决定它们的具体缺口。若问题后立即转向下一位作者或下一个主题，先补完缺失的推理，再处理分段和措辞。按文类判断结论由什么支持，引言与摘要是否对应最终稿；不把这套检查写进正文，也不据此预设段数或段长。完整研究稿成稿后，实际读取 [审读与修订](modules/review.md)，按当前稿件完成一次审读并落实必要修改；不能以已写“自检完成”代替检查。局部委托只检查获准范围。检查关键引文与参考文献对应关系；缺少决定性来源时调整主张或准确标注。

用户只要润色时保留结构、术语、归属、否定和模态；影响成立与否的问题可简短指出，不擅自重写立场。全文委托则完成必要实质修改，并交付可用文件或聊天正文。格式工具存在时按该格式技能制作和验证，不能把 Markdown 改后缀称为 Word。

## 专项配合与语言支持

按当前困难实际读取专项：需要展开原文用 [细读](modules/close-reading.md)，概念关系未清用 [概念工作](modules/concept-work.md)，推论未完成用 [论证](modules/argument.md)。几个问题相互依赖时一并使用，不以写作入口独自代替这些工作；已完成的分析直接接续。

只做语言工作的，沿用 [中文写作](resources/humanities-writing/references/chinese-academic-writing.md)、[英文写作](resources/humanities-writing/references/english-academic-writing.md) 或 [翻译与术语](resources/humanities-writing/references/translation-and-terminology.md) 中适用部分。引言与贡献表述另见 [开篇路线](resources/humanities-writing/references/introduction-route.md)、[贡献范围](resources/humanities-writing/references/contribution-patterns.md)，不规定固定结构。

只处理模板词句时实际读 [词汇句式](modules/ai-style-editing.md)；有空泛辩解或重复边界时一并读 [防御性表达](modules/defensive-editing.md)。只要编号方案就只交方案；只选了部分编号就只落实那些编号。保持两项独立判断，一处只改一次。
