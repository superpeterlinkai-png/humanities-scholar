# 人文学术写作

起草或实质改写，读 [成文模块](modules/writing.md)，接续实际材料与已经展开的分析。只改词句或按编号落实时，直接读所需的 [词汇句式](modules/ai-style-editing.md) 或 [防御性表达](modules/defensive-editing.md)，守住所选范围。翻译按 [翻译与术语](resources/humanities-writing/references/translation-and-terminology.md) 处理。

读 [共同约定](resources/humanities-research/references/research-contract.md)；本任务已读且未变化则沿用。模块处理同一份工作文本，不重复概括、建提纲或重启检查。只有实际读取相应文件才能说明本次使用了该模块。

需要解释原文、辨明概念或完成推论时，按需使用 [细读](modules/close-reading.md)、[概念工作](modules/concept-work.md)、[论证](modules/argument.md)。代本机用户起草、实质改写或审查作者声音时读 [作者声音](modules/author-voice.md)。普通语言编辑和翻译按委托范围完成。

研究方法随问题选择，文类随实际任务确定。起草中的实质分析、成稿后的学术审读及表达编辑各做所需工作；达到交付标准即完成，已做检查直接沿用。跨步骤接续见 [持续项目](resources/humanities-research/references/project-continuity.md)。
