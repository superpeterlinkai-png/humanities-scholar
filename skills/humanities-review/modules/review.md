# 学术审读与修订

读 [共同约定](../resources/humanities-research/references/research-contract.md)。先识别文类、研究阶段、用户要评价还是直接修改。探索稿不按成稿惩罚，课程论文不按博士论文扩充，成熟论证不强造缺点。

用最强合理版本重建论文主张与支持方式，再判断是否成立。方法标准按 [方法适配](../resources/humanities-research/references/method-router.md) 选择。核实实际读取范围；只能检查节选时，不给全文已合格的判断。

优先检查会改变结论的地方：关键材料是否支持对应解释；作者归属和版本是否正确；竞争解释是否被公平处理；声称反驳作者或用户旧稿时，被批评的命题是否能在原文及其相邻论证中定位，是否与原文后续保留相容；无法归属的强版本改作明确的条件性延伸，不再用其失败宣称已经反驳原作者；描述、历史、经验、规范或本体判断之间是否偷换；引言承诺与结论是否相符。每条实质意见应有具体位置、问题理由、影响与可执行修法，不能只写“加强理论深度”。

区分决定性问题、可修正局限、合理学术分歧与表达问题。已成立的部分要说明依据，保持与批评相称。评分只在用户或实际制度需要时给出，并说明标准；不要以不透明总分替代判断。

反例审查要核对它是否保留了原命题的条件、概念用法和模态，且产生真正冲突的结果。局部限定修好后，继续检查后文直接归给该作者的说法和摘要、结论中的复述；开头准确不代表全文归属已修复。判断修正是否奏效须读实际改稿，不能只凭修改说明。

用户要求修改时直接修复最小必要范围，追踪关键改动对其他段落、引言、结论与摘要的影响。证据不足时缩小、补证或撤回主张。把准确范围与归属写进修正后的解释；对旧稿的纠错留在修改说明。完整研究稿的审读，实际读取 [防御性表达组件](defensive-editing.md) 与 [词汇句式组件](ai-style-editing.md)，再检查全文并落实授权内修改；不要等生成者先自行发现缺陷才决定是否读取。专项或局部委托只读所需组件、处理指定范围。没有实际问题的词句原样保留；仅审阅时列方案，不写回文件。若多段只重复同一边界，按任务范围完成被挤掉的材料分析。连读相邻段落，判断后段如何使用前段取得的认识，分段是否对应实质转折。若短段反复以作者观点起头、解释后以泛泛追问收尾，修复它们之间未完成的推理；单纯合段或改写开头不能完成这种修订。

长稿审读先从实际成稿重建主要支持链，再把相隔较远、承担相似作用的段落放在一起比较：后处改变了哪项前提、取得了什么结果，或让已有结论承担了什么新工作？换标题、例子或术语本身不构成推进。若去掉后处只少一次已完成的证明，就沿用先前结论，缩为当前推理所需的回指；保留真正检验、修正或应用它的材料，以及有文类作用的总结。依据全文需要做实际比较，并在现有审读记录中留下决定修改或保留的位置和理由，不把这份工作记录写进正文。不能只凭相邻段流畅、没有逐字重复、达到字数或一句“自审完成”判定长稿合格。修订后回读主论证，检查删掉重复证明是否留下缺失的前提或来源。语言调整保留作者的概念、节奏与思想取舍。

回应评审时先区分对方的事实纠错、论证要求、文类偏好和可能误解。逐项明确接受、部分接受或有理由地保留；对应实际改动与定位。未做的修改不写“已完成”，不为讨好评审接受会破坏论证的要求。必要时诚实说明材料限制。

完成相关修订与必要检查后交稿，简要说明影响判断的变化和仍未解决的限制。纯审稿委托交审读意见；不要擅自改原文件。全流程委托继续完成格式和文件验证，不停在评审清单，也不未经授权发送或投稿。

需要核实关键出处、解释或推论时，实际调用 [材料检索](source-discovery.md)、[细读](close-reading.md) 或 [论证](argument.md) 中所需项；声音审查才读 [作者声音](author-voice.md)。按稿件问题组合使用，保留审阅与修改的授权区别。LaTeX 文件另按需读 [格式复核](../resources/humanities-review/references/latex-rules.md)。
