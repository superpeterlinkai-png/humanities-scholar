# 问题与研究设计

读 [共同约定](../resources/humanities-research/references/research-contract.md)。研究设计的产物是值得解决的问题及其实际研究办法；题目和提纲是由此产生的表达。

从已有文本、材料或争论中找一个会改变理解的困难：某个解释无法处理的细节、概念的双重用法、前提与结论的张力、历史材料与通行说法的不吻合。若只有兴趣，先进行小范围资料定位或材料分析，提供有理由的暂定问题，不要求用户先替你找出研究空白。

把主题转为问句时同时确定：要解释的对象、需要判定的关系、为什么现有答案不够、哪些材料或论证能够区分可能答案。区分“某作者如何理解 X”与“其关于 X 的论证是否成立”，也区分“某群体如何行动”与“他们应如何行动”。

从用户旧稿发展问题，先找出其实际论点和保留；旧稿不是用户当前立场的证明。尚未写出的连接可以成为研究问题，不能先认定为错误再为它设计反驳。试探若支持原解释，也据此推进，不为维持选题的新颖性强造缺陷。

路线尚未确定时提出少量有实质差异的候选，比较材料取得、语言要求、思想收益与任务规模，推荐当前最有希望的一条并完成一次试探。除非用户只要选题清单，否则不要以清单结束。试探应产生一段细读、一个论证或一次检索结果，检验问题是不是实际存在。

按 [方法适配](../resources/humanities-research/references/method-router.md) 选择支持方式。研究计划应交代材料怎样取得与分析，哪种发现会要求改变暂定主张。篇章安排应服从这些推论关系，避免每个理论家占一章而最终没有共同问题。

课程论文聚焦一个有意义、可辩护的推进；博士计划还需要查证对话对象、贡献、语言和材料可行性，以及项目如何持续发展。博士章节应各有任务并共同解决主问题，不靠扩大对象数量制造规模。若用户要求申请匹配，现查项目与导师资料，区分有相关研究与愿意招生。

交付明确问题、暂定判断、研究办法及已完成的试探；按请求写成研究计划、开题说明或可用引言。尚未证实的原创性与结果保留未来时态。全流程委托中，把决定与材料传回 [研究入口](research.md) 继续执行。

博士计划或申请的实质修订，按需读 [博士研究设计](../resources/humanities-question-design/references/doctoral-proposals.md)。需要从材料发展暂定判断时，与 [细读](close-reading.md)、[论证](argument.md) 一并使用；缺少关键文献再用 [材料检索](source-discovery.md)，不用题目清单代替试探。
